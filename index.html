Owner instructions

Add your own book PDFs

This website is static, so adding books is simple and fast.

1

Copy the PDF

Place your PDF file inside assets/books/. Example: my-book.pdf.

2

Sync the catalog

Run python tools/sync_catalog.py, then python tools/verify_catalog.py. Any PDF in assets/books/ will be added to script.js so it appears on the site.

3

Publish

Upload the whole MindBook folder to your hosting. Readers can read and download immediately.
